## About Me

I'm a Data Science M.S. graduate who builds data products from start to finish: pulling and cleaning raw data, modeling it, and shipping the result as a dashboard, an app, or a forecast someone can use.

My graduate work covers **NLP and text mining**, **distributed ML with Spark**, **time-series forecasting**, **deep learning for computer vision**, and **interactive data visualization**. Before data science I trained as a full-stack software engineer, so I care about clean pipelines, reproducible code, and tools people actually use.

I'm looking for **entry-level roles in data science, machine learning, analytics, and data engineering**.

      <p>Team NLP pipeline that measured how news outlets covered the 2025 U.S. tariff policy. It pulls articles from NewsAPI into SQLite, scores them with SentiWordNet, trains TF-IDF + Naive Bayes classifiers, finds topics with LDA, and serves predictions in a Streamlit app.</p>
